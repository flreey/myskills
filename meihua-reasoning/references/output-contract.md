# Output Contract

Use the following headings. Keep the answer readable; YAML is optional unless the user requests machine-readable output.

## 1. Frozen question

- exact question
- horizon
- observable success condition
- casting method and inputs
- timezone when relevant
- context known at casting time
- scoreability: `可评分` or `不可评分`

## 2. Mechanical result

- primary / mutual / transformed hexagrams
- moving line
- body / function and five-element relation
- convention notes or calculation limitations

## 3. Candidate mappings

Use a table:

| Level | Symbol | Reality mapping | Support | Objection | Discriminator |
|---|---|---|---|---|---|

Keep only candidates that can affect the path ranking.

## 4. Competing paths

For each of `主路径`, `最强反方`, `阶段转换`, and `空模型`, state:

- mapping chain;
- expected observable sequence;
- supporting facts;
- failure point.

## 5. Reality check

Separate:

- facts available before interpretation;
- new external evidence;
- conflicts between symbolic and conventional analysis.

## 6. Testable conclusion

- selected path and runner-up
- mapping confidence: low / medium / high
- bounded claim
- verification events
- invalidation events
- evidence that would change the ranking
- safe, reversible next action

## 7. Boundary statement

Use a short statement appropriate to the stakes. For ordinary reflection, say the result is a symbolic hypothesis. For high-stakes use, state that action must rely on conventional evidence and risk controls rather than the reading alone.
