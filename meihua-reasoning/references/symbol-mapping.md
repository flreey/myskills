# Symbol Mapping Rules

Use this reference after the mechanical cast, never to select the cast.

## Evidence levels

### A — 经典原生象

Keep this layer conservative. It supplies a semantic field, not a concrete prediction.

| Trigram | Element | Core images and qualities |
|---|---|---|
| 乾 Qian | 金 | 天、健、创始、主导、父 |
| 兑 Dui | 金 | 泽、悦、口、交流、缺口 |
| 离 Li | 火 | 火、日、明、目、附着 |
| 震 Zhen | 木 | 雷、动、惊、起始、长男 |
| 巽 Xun | 木 | 风、入、渐进、渗透、长女 |
| 坎 Kan | 水 | 水、险、陷、流动、隐伏 |
| 艮 Gen | 土 | 山、止、界限、门径、少男 |
| 坤 Kun | 土 | 地、顺、承载、众、母 |

### B — 现代稳定延伸

A B-level mapping must preserve at least two properties of the A-level semantic field and recur across contexts. Examples:

- Li → visibility/display/attention, because it preserves brightness and attachment;
- Kan → liquidity/logistics/risk channel, because it preserves flow and danger;
- Gen → access control/stopping rule, because it preserves boundary and stopping;
- Xun → distribution/network penetration, because it preserves entry and gradual diffusion.

Do not promote a fashionable one-off analogy to B level.

### C — 本次情境假设

A C-level mapping binds a symbol to a named actor, variable, or mechanism in this question. Example: “Kan maps to leveraged-liquidation risk in this BTC question.” It is allowed only when:

1. the actor or mechanism existed in the frozen context;
2. the mapping preserves a relevant A/B property;
3. an observation can support or reject it.

## Selection test

For each candidate, answer:

1. Why this object rather than another object in the same semantic field?
2. Which known context supports it?
3. What contradicts it?
4. What observation distinguishes it within the stated horizon?
5. Would the mapping have been proposed before knowing the outcome?

Reject the mapping if questions 1, 4, or 5 cannot be answered.

## Relationship translation

Translate five-element relations into neutral system language first:

| Traditional relation | Neutral reading |
|---|---|
| 用生体 | environment/resources may support the subject |
| 体生用 | subject may expend resources into the matter |
| 体克用 | subject may control the matter at a cost |
| 用克体 | matter/environment may constrain the subject |
| 比和 | similar forces or lower structural friction |

Only then propose context-specific mechanisms. These relations do not encode direction, magnitude, timing, or certainty by themselves.

## Anti-patterns

- Keyword matching: “Li is fire; AI uses electricity; therefore AI stocks rise.”
- Hidden-cause escape: “Kan means an unknown secret event,” with no observable discriminator.
- Meaning drift: the same Kan means liquidity in the main path and fear in the contrary path without marking an alternative mapping.
- Outcome leakage: selecting “crash” only after learning that price fell.
- Exhaustive association dumping: listing dozens of images without ranking or rejection.
