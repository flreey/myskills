# SERP 弱度判断（G3）

G3 回答的问题是：**一个新域名做一个合格的页面，能不能挤进这个词的前 10–30？**
以实看的 SERP 为主，哥飞版 KD 为辅。两者冲突时以 SERP 为准，并把冲突记下来。

## 怎么数

- **范围**：目标市场的自然结果前 10。不算广告、视频格子、PAA、图片包。
- **一条结果只归一类。** 弱页计 1，强页计 0，其余为中性。
- **同时记录 SERP 特性**：Google 自带工具、答案框、AI Overview 占了首屏时，需求档降一档（点击被截走），但不影响可排名的判断。

## 弱页（计数）

| 类型 | 识别方法 |
|---|---|
| 论坛 / UGC | Reddit、Quora、各类社区帖子、Facebook 群组，或主题不对口的 StackExchange 问答 |
| 意图不对 | 用户要的是工具，结果却是文章；用户要具体格式、版本或场景，结果却是泛泛的页面 |
| 大站顺带提及 | 大站的页面并不针对这个词：标题里没有核心词，或者这个词只是列表里的一项 |
| 低权重小站 | DR < 20，或域龄不到 1 年（有数据时才算；`keyword_difficulty` 会给出这两项） |
| 过时或坏掉 | 年份明显过时、工具打不开、404 或软 404、广告盖住主要内容 |
| 薄页 | 几乎没有正文，或模板批量生成、各页只换了词 |

新词的 SERP 往往很稀：前 10 里和这个词不相关的结果，都按“意图不对”计为弱页。

## 强页（不计）

- 官方或品牌本身的页面、维基百科。
- 成熟工具站的专门页面：标题精确匹配，功能完整，DR ≥ 50。
- 排名稳定、内容完整的权威内容页：头部媒体、政府、教育机构。

## 可排名档位（默认线）

| 档 | 条件 |
|---|---|
| 3 | 弱页 ≥ 5，或前 3 名里有弱页 |
| 2 | 弱页 3–4 |
| 1 | 弱页 1–2。只有新词或成本为 1 时才进入“做”，其余放进观察 |
| 不过 G3 | 弱页为 0 |

## 哥飞版 KD（进入短名单前精评）

| KD | 处理 |
|---|---|
| < 20 | 可排名档 +1，不超过 3；弱页为 0 的词不会因此救回 |
| 20–29 | 维持 SERP 判出的档位 |
| 30–39 | 必须弱页 ≥ 3，否则降一档 |
| ≥ 40 | 不过 G3。例外：新词，且弱页 ≥ 3，此时记为 1 档 |

- 批量预筛分（`bulk_keyword_difficulty`、`keyword_ideas` 里的预筛难度）和哥飞版 KD 不是同一口径，不放在一张表里比大小，也不套上面的阈值。
- 没有付费精评时，只用 SERP 判档，并在表里标“KD 未查”。

## 冲突与特殊情况

- **KD 低但 SERP 全是强页**：以 SERP 为准，记“KD/SERP 冲突”。这类词上线后要重点回看，用来校准。
- **KD 高但弱页很多**（常见于大站顺带提及）：按弱页判档，但最多 2 档。
- **已有站点**：DR 明显高于新站时，可排名档可以 +1。按站点实际 DR 说明理由，不套用新站的假设。
- **混合意图**：前 10 里工具和文章各半时，按你打算做的页面类型来数弱页，并在上线卡里写明页面类型。

## 校准

`radar-log.md` 里累计到 10 个以上有 D28 结果的页面后：

1. 按可排名档和 KD 段统计“D28 平均排名 ≤ 30”的比例。
2. 某一档的命中率明显偏离预期（比如 2 档命中率不到 20%，或 1 档超过 50%）时，修改本文件的默认线。
3. 在 `radar-log.md` 末尾写一行：日期、旧线、新线、样本数、依据。

没有这类数据时不要改默认线。
