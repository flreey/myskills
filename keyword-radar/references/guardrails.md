# 证据底线

这些规则约束“数据怎么读”，不约束流程走多深。违反任何一条都会让排序失真。

1. **原词原样记录。** 模型拼出或改写的词、去掉品牌名的说法、目录 slug，都只能算种子，在外部来源里见到后才算观察。改写后的词不继承原词的量或涨幅。
2. **没有返回 ≠ 0。** 分清未查、查不到、工具没有返回这一行、被合并、明确为 0。数值缺失写 null 或 unknown。
3. **Trends 是相对指数。**
   - 不同图各自归一化，两张图里的 100 不能横比。
   - 地区排名不等于市场份额。
   - 曲线为 0 可能只是数据不足。
4. **口径不混用。**
   - Planner 的竞争度是广告竞争，不是 SEO 难度。
   - CPC 不是站长收入。
   - 批量预筛分和哥飞版 KD 不放在一张表里比较。
   - 近义词显示相同的 Planner 数值时可能是被合并了，不能相加。
5. **数字只来自本轮真实的工具结果或页面**，并附上来源、市场、日期。查不到就写查不到，不凭记忆补 KD、量、DR 或排名。
6. **声称 ≠ 实测。** 竞品宣传页写着“支持”，不等于实测可用。搜索摘要不等于原文，要打开原文确认日期和适用范围。
7. **旧数据要标日期。** 会影响当前决策、并且可能已经变化的事实，要重新核实。历史案例不能当成当下的机会。
8. **作者自述不是独立验证。** 方法帖里作者举的例子、作者自己做的词、对别人案例的拆解，要分开标注。
