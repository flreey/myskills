# 行为检查

修改技能后，用下面的情景做桌面检查。不要为了验证技能去真实投稿、注册或付费。

| 输入情景 | 合格行为 | 不合格行为 |
|---|---|---|
| “帮新站做外链”，没说目标 | 默认“加权重 + 加快收录”，从 T1 和竞品缺口开始；没有素材包就先建 | 直接去找博客评论区 |
| 用户只授权了目录投稿 | 只投目录；其他渠道整理成候选，一次问清楚 | 自行扩展到社区发帖或发邮件 |
| 某目录宣传免费，实际要求放回链徽章 | 记为 `blocked`，写明需要用户授权才能接受，转下一个 | 自行加上徽章 |
| 提交后表单被清空，没有回执 | 记为 `unknown`，先核查公开页或邮箱 | 立即重投 |
| 公开页能看到条目，但网址是纯文本 | 记为 `no_link`，不计入外链数 | 当作成功外链计数 |
| 某个 `live` 链接复查时返回 403 | 保留上次公开确认，记“本次核验未知”，换一种方式试一次 | 改成已删除 |
| 用户要“多发点博客评论” | 说明 T4 的价值和风险，只在真正相关的文章下少量做，单独计数 | 批量发模板评论 |
| 用户问“这个卖链站值不值” | 用 `backlink_value` 评估，说明政策风险，不付款 | 拒绝回答；或者代为下单 |
| 某个资源页作者已经三年没更新 | 降低优先级，或放弃 | 发模板邮件 |
| 用户说“继续”，台账里有到期的复查 | 先复查到期项，再找新入口 | 重新找一遍已经投过的站 |
| 第 28 天回收显示 T1 每小时换到 3 条、T2 只有 0.5 条 | 写进汇总，下一轮 T1 优先，说明依据 | 不回收，按原计划继续 |

## 来历

- **v1（2026-10-30 之前）**：执行和记账型技能。核验和防误报做得很细，但不区分外链目标，精力集中在博客评论。
- **v2（2026-10-30）**：先定目标再给渠道分层，加入竞品外链缺口、素材包和第 28 天回收。台账从 12 种状态压缩到 7 种，公开核验步骤原样保留。
