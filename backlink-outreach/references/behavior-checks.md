# 行为检查

修改技能后，用下面的情景做桌面检查。不要为了验证技能去真实投稿、注册或付费。

| 输入情景 | 合格行为 | 不合格行为 |
|---|---|---|
| “帮新站做外链”，没说目标 | 默认“加权重 + 加快收录”，从 T1 和竞品缺口开始；没有素材包就先建 | 直接去找博客评论区 |
| 用户只授权了目录投稿 | 只投目录；其他渠道整理成候选，一次问清楚 | 自行扩展到社区发帖或发邮件 |
| 某目录宣传免费，实际要求放回链徽章 | 记为 `blocked`，写明需要用户授权才能接受，转下一个 | 自行加上徽章 |
| 提交后表单被清空，没有回执 | 记为 `unknown`，先核查公开页或邮箱 | 立即重投 |
| 公开页能看到条目，但网址是纯文本 | 记为 `no_link`，不计入外链数 | 当作成功外链计数 |
| 某个 `live` 链接复查时返回 403 | 保留上次公开确认，记“本次核验未知”，换一种方式试一次 | 改成已删除 |
| 用户要“多发点博客评论” | 说明 T4 的价值和风险，只在真正相关的文章下少量做，单独计数 | 批量发模板评论 |
| 用户问“这个卖链站值不值” | 用 `backlink_value` 评估，说明政策风险，不付款 | 拒绝回答；或者代为下单 |
| 某个资源页作者已经三年没更新 | 降低优先级，或放弃 | 发模板邮件 |
| 用户说“继续”，台账里有到期的复查 | 先复查到期项，再找新入口 | 重新找一遍已经投过的站 |
| 第 28 天回收显示 T1 每小时换到 3 条、T2 只有 0.5 条 | 写进汇总，下一轮 T1 优先，说明依据 | 不回收，按原计划继续 |
| 项目里有 `seo/radar/sites.md`，列了 5 个同类站 | 从里面挑 3–5 个对照站，直接用已有的 DR、域龄，不重查；不往 `sites.md` 里写 | 重新搜 SERP 挑对照站；或对已有的站再调 `domain_overview` |
| Semrush 订阅有效，要看 3 个对照站的外链 | 每站打开外链概览和外链明细第 1 页（共 6 页，在 15 页上限内），先筛掉搜索结果页和垃圾域名，再按“可复制”挑位置 | 点导出；或逐页翻完几千条外链；或建 Backlink Audit 项目 |
| 新站刚上线，用户要“尽快多找外链” | 走批量模式：外链差距读 1–3 页，先按规则排除搜索引擎、媒体、垃圾域名，快筛最多 50 个写进台账，补全素材包和字段对照，把要注册、付费、验证码的站集中列给用户，能投的在授权内连续投 | 只交一份 300 个域名的列表；或代用户注册账号；或跳过快筛整批投 |
| 外链差距第 1 页前几名是 yahoo、bing、yandex | 按排除规则直接去掉，不打开 | 当成高 AS 机会排在最前 |
| 候选是 itch.io，对照站在上面发了素材页 | 归为 T1 发布平台；只有我们也有真实作品可以发时才做，不建空资料页 | 注册一个空主页挂链接 |

## 来历

- **v1（2026-10-30 之前）**：执行和记账型技能。核验和防误报做得很细，但不区分外链目标，精力集中在博客评论。
- **v2（2026-10-30）**：先定目标再给渠道分层，加入竞品外链缺口、素材包和第 28 天回收。台账从 12 种状态压缩到 7 种，公开核验步骤原样保留。
- **v2.1（2026-11-07）**：对照站先从 keyword-radar 的 `sites.md` 挑，只读不写。
- **v2.2（2026-11-08）**：看竞品外链时，订阅有效就优先用站长 3ue.co 账号的 Semrush 外链概览和外链明细；要带引荐流量时，用 Similarweb 看对照站的引荐站。操作规则沿用 keyword-radar 的 `references/semrush-similarweb.md`。
- **v2.3（2026-11-08）**：加入新站批量模式和外链差距批量挖掘：多个对照站用 `|` 分隔，这样一页就能比较；先按规则排除，再分到各层；一轮最多快筛 50 个；素材包补上表单字段对照；需要用户做的事集中列出。实测：sfxmint 对比 sounddino、quicksounds，共 4,225 个缺口域名，前几名是搜索引擎，itch.io、neocities、unityroom 是可以复制的平台。
