# 素材包 backlink-kit.md

每个产品准备一次，所有投稿都从这里取。

- 内容必须是**当前可以核实的事实**，比如价格、免费额度、许可证。产品变化后，先更新素材包，再继续投稿。
- 放在 `<项目>/seo/backlinks/backlink-kit.md`。图片放同目录下的 `assets/`。

```markdown
# <产品名> 投稿素材包
更新：YYYY-MM-DD｜核实来源：<页面或文件>

## 基本
- 名称（统一写法）：
- 主站网址：
- 推荐落地页：首页 / <工具页 A>：用途 / <文档页>：用途
- 分类和标签（按常见目录的分类选 3–5 个）：
- 价格模式：免费 / 免费增值 / 付费；免费额度和限制：
- 平台：Web / Chrome 扩展 / iOS / API …
- 上线日期：

## 文案（多种长度，按字段裁剪，别现场重写）
- 标语（≤ 60 字符）：
- 一句话（≤ 160 字符）：
- 短介绍（≈ 300 字符）：
- 长介绍（≈ 800 字符，含 3 个具体用例）：
- 核心功能（3–5 条，每条 ≤ 80 字符）：
- 和替代品的区别（1–2 句，只写可以核实的）：

## 图片（assets/）
- logo：方形 PNG，512×512 与 256×256；透明背景版
- 截图：3–5 张，1280×800，首张展示主要功能
- 社交卡片：1200×630

## 身份（只填用户授权的）
- 署名 / 品牌名写法：
- 联系邮箱：
- 与产品的关系（投稿时要披露）：
- 社交账号：

## 不能说的
- 未经核实的数字（用户量、准确率）、不存在的功能、竞品的负面说法
```

## 使用规则

- 字段长度不够时，从更长的版本裁剪，不现场编新说法。
- 目录要求的分类里没有合适的，选最接近的一个，并在台账里记下来。
- 账号、密码、编辑密钥**不放进素材包**，放在项目约定的私有位置。
