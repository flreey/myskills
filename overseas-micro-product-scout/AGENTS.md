# AGENTS.md

## Overseas Micro Product Scout usage

When the user asks to discover, evaluate, rank, or differentiate overseas micro-product opportunities, use the local skill in:

`overseas-micro-product-scout/SKILL.md`

Use it for: tool sites, browser extensions, platform plugins, file converters, QA/preflight checkers, diff tools, overlays, report generators, and competitor-adjacent indie product ideas.

Default boundary:

- overseas users only
- no China-user products
- no local-regulatory domains such as tax, legal, medical, insurance, government procurement, construction estimating, landlord law, or school administration
- data source must be visible: URL, current webpage, screenshot, HTML, Markdown, CSV/XLSX, transcript, sitemap, public export, or pasted text
- competitor-first research; do not propose ideas without scanning paid/free alternatives
- reject "same thing but free" clones

Workflow:

1. Restate the user's boundary and personal fit.
2. Use current web research for competitor features, pricing, marketplace listings, users/ratings, and recent reviews.
3. Mine real complaints and workarounds using phrases like "too expensive", "overkill", "I just need", "manual", "spreadsheet", "before I publish/import/record/share".
4. State the wedge as: "Competitor does X. This product only does Y for Z user at W moment."
5. Validate data-source fit and choose product form by where the data lives: browser extension, tool site, platform plugin, add-on, CLI, or light SaaS.
6. Score 7 gates: competitor demand, wedge, visible data, low domain knowledge, distribution, credible pricing, 7-10 day demo.
7. Output DO / OBSERVE / KILL, with a 7-10 day validation MVP and kill criteria.

Do not output generic idea lists. Do not invent quotes, URLs, pricing, install counts, or reviews. If evidence is weak or blocked, label it partial/low confidence.
